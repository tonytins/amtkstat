## 🔨 Setup

### Prerequisites

You will need Swift Bundler to properly run and bundle your app.

1. ``brew install mint``
2. ``mint install stackotter/swift-bundler@main``

### Running

```
swift-bundle run
```

### Bundling

```
swift-bundler bundle -c (release|debug)
```
